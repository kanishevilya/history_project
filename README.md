# Судоходная история Санкт-Петербурга

Интерактивный веб-проект о морской истории города: навигационный стол с картами разных эпох и пять тематических глав — от основания Петербурга до XXI века.

**Стек:** [Next.js](https://nextjs.org/) 16 (App Router), React 19, TypeScript, Tailwind CSS, Framer Motion, GSAP.

---

## О проекте

| Раздел | Содержание |
|--------|------------|
| **Главная** (`/`) | Хронологическая карта Санкт-Петербурга, переключение эпох, метки объектов, переходы в главы |
| **Глава I** (`/chapter-1`) | XVIII век — основание порта, каналы, верфи, флот |
| **Глава II** (`/chapter-2`) | XIX век — пароходство, промышленность |
| **Глава III** (`/chapter-3`) | Первая половина XX века — войны, блокада, «Дорога жизни» |
| **Глава IV** (`/chapter-4`) | Послевоенный период — ЕГС, контейнеризация, БМП |
| **Глава V** (`/chapter-5`) | XXI век — «Морской фасад», логистика, цифровая эпоха |
| **Источники** (`/sources`) | Библиография и список материалов проекта |

Тексты и данные вынесены в `constants/`, иллюстрации лежат в `public/assets/`.

## Что нужно для запуска

Для проекта нужен **Node.js** (версия **18.18+** или **20+**). Вместе с Node.js устанавливается **npm** — менеджер пакетов, через который ставятся зависимости и запускаются команды.

### Где скачать Node.js и npm

1. Откройте официальный сайт: **[https://nodejs.org/](https://nodejs.org/)**
2. Скачайте **LTS**-сборку (рекомендуется для большинства пользователей).
3. Установите с настройками по умолчанию (галочка «Add to PATH» должна быть включена).
4. Перезапустите терминал (PowerShell, CMD или встроенный терминал в VS Code / Cursor).

Проверка установки:

```bash
node -v
npm -v
```

Должны появиться номера версий, например `v22.x.x` и `10.x.x`.

> **Альтернатива:** в репозитории есть `pnpm-lock.yaml`. Если пользуетесь [pnpm](https://pnpm.io/), замените в командах ниже `npm` на `pnpm` (`pnpm install`, `pnpm dev` и т.д.).

## Быстрый старт

### 1. Клонировать или открыть папку проекта

```bash
cd путь\к\
```

### 2. Установить зависимости

```bash
npm install
```

Выполняется один раз после клонирования или при обновлении `package.json`.

### 3. Запустить режим разработки

```bash
npm run dev
```

Откройте в браузере: **[http://localhost:3000](http://localhost:3000)**

Остановка сервера: `Ctrl + C` в терминале.

### 4. Сборка для продакшена (по желанию)

```bash
npm run build
npm start
```

Сайт будет доступен на [http://localhost:3000](http://localhost:3000) в оптимизированном виде.

### Другие команды

| Команда | Назначение |
|---------|------------|
| `npm run dev` | Локальная разработка с hot-reload |
| `npm run build` | Продакшен-сборка |
| `npm start` | Запуск собранного приложения |
| `npm run lint` | Проверка ESLint |

## Структура проекта

```
first_page_v1/
├── app/                    # Маршруты Next.js (страницы и стили глав)
│   ├── page.tsx            # Главная
│   ├── home-gis.css        # Стили навигационного стола
│   ├── chapter-1/ … chapter-5/
│   └── sources/            # Страница источников
├── components/             # React-компоненты
│   ├── home/               # Главная (карта, эпохи)
│   ├── chapter/            # Общие элементы (кнопка «Главная», чтение)
│   ├── chapter2/ … chapter5/
│   └── sources/
├── constants/              # Тексты, метаданные, карты, библиография
│   ├── homeMap.ts
│   ├── chapter1.ts … chapter5.ts
│   └── sources.ts
├── public/assets/          # Изображения по главам (ch1, ch2, … home)
├── content_*.txt           # Исходные тексты глав (референс)
├── design_guidelines.json  # Визуальные правила (глава I)
└── package.json            # Зависимости и npm-скрипты
```

### Логика слоёв

- **`app/`** — только маршрутизация, layout и подключение CSS глав.
- **`components/`** — вёрстка, анимации, интерактив (карта, секции, таблицы).
- **`constants/`** — весь контент на русском; правки текста удобнее делать здесь.
- **`public/`** — статика, отдаётся по URL `/assets/...`.

## Частые проблемы

| Симптом | Что попробовать |
|---------|------------------|
| `npm` не найден | Переустановите Node.js с [nodejs.org](https://nodejs.org/), перезапустите терминал |
| Ошибка при `npm install` | Проверьте версию Node (`node -v` ≥ 18), удалите `node_modules` и снова `npm install` |
| Порт 3000 занят | `npm run dev -- -p 3001` и откройте `http://localhost:3001` |
| Картинки не видны | Убедитесь, что файлы есть в `public/assets/` (пути заданы в `constants/`) |
